# ⚔️ Clash Royal · 简化版皇室战争 · Fairy Tail Edition

一个简化版的皇室战争(Clash Royale)风格游戏项目,角色换装为《妖精的尾巴》(Fairy Tail)全员。

## 🎮 玩法设想

- 双人对战:你与 AI 各守一路,摧毁对方国王塔获胜
- 消耗圣水(💧 Elixir)在场上部署卡牌单位
- 单位自动前进、索敌、攻击,卡牌类型:
  - 🗡️ 近战单位(格雷、艾露莎)
  - 🌊 远程单位(朱毕安、斯汀 & 罗格)
  - 🔥 法术(纳兹 · 火龙的咆哮)
  - ✨ 建筑/结界(梅比斯)

## 🛠️ 技术方案

| 项目 | 方案 |
|---|---|
| 实现 | HTML5 Canvas + 原生 JavaScript |
| 结构 | 3 个页面 + 共享 js 模块(无框架、零依赖) |
| 运行 | 浏览器直接打开,离线可用 |

## 🚀 运行

```bash
git clone https://github.com/AlghaPorthos/clash_royal.git
cd clash_royal
open index.html   # macOS;Windows 双击 index.html
```

## 📁 目录结构

```
clash_royal/
├── index.html      # 开始页 · 可爱团战海报(双方队伍对峙)
├── game.html       # 对战页(电影感加载海报 + 大战场)
├── guidance.html   # 游戏指南页(How to Play)
├── assets/         # 海报参考图 + 角色头像裁剪(妖精的尾巴美术)
│   ├── poster_guild.jpg   # 公会合影海报(开始页背景/头像来源)
│   ├── poster_clash.jpg   # 对决海报(加载页/结算背景)
│   └── p_*.png            # 9 张角色头像(朱毕安/格雷/艾露莎…)
├── js/
│   ├── i18n.js     # 中英双语词典(默认 English)
│   ├── chars.js    # 角色数据 + 头像加载 + 战场单位令牌绘制
│   ├── guidance.js # 指南内容生成(页面与游戏内共用)
│   └── themes.js   # 四季战场主题(地形渲染/环境粒子/选择器)
└── README.md
```

## ✨ 本次升级(Fairy Tail Edition)

- **三重视觉体验**:可爱团战开始页(双方队伍头像对峙 + 粒子光效)→ 电影感加载海报(对决构图 + 轮播 TIP)→ 大战场对战
- **角色主题**:8 个卡槽全部映射为妖精的尾巴角色,头像取自海报参考图,战场以"头像令牌 + 阵营光环"呈现
- **大战场**:画布自适应填充视口(位图随 DPR 缩放保持清晰),预渲染草地纹理/小径/花丛/石块
- **双堡垒**:玩家方为亮色欧式城堡(雉堞 + 蓝旗),敌方为暗色尖顶要塞(紫黑锥顶 + 红旗)
- **登场演出**:魔法召唤阵 + 光柱 + 粒子 + 冲击波环;王塔损毁有轻微震屏
- **UI 升级**:头像卡牌、分段圣水条、计时/皇冠栏、海报风胜利/败北结算
- **游戏内指南**:对战页 ❓ 按钮随时打开指南,阅读时自动暂停;独立指南页 guidance.html
- **中英双语**:🌐 按钮全页面切换 English / 简体中文(默认 English,localStorage 记忆)
- **结算导航**:胜利/战败面板提供 重新开始 / 再来一局、主页、指南 按钮,点击场地亦可重开
- **页面导航**:对战页顶栏 🏠 主页 按钮;指南页 ← 返回主页;指南弹窗关闭即返回战斗
- **四季战场主题**:☀️ 夏 / 🍂 秋 / ❄️ 冬 / 🌸 春 四套环境(地形、河流、植被、飘落粒子全部更换),开始页与对战内均可选择,柔和光效过渡,localStorage 记忆偏好,玩法完全不变
